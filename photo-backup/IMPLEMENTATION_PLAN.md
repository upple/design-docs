# 구현 계획 및 인수 테스트

## 1. 단계별 구현

### P0 — 저장소 및 개발 골격

- 모노레포 또는 단일 저장소 구조 확정
- FastAPI, Flutter, React 프로젝트 골격 구성
- 개발/운영 환경 변수와 secret 분리
- DB migration과 기본 테스트 환경 구축
- 외장 SSD 마운트 guard 및 헬스 체크 설계

완료 조건: 서비스가 DB와 저장소를 확인하고 SSD가 없으면 쓰기 기능을 사용 불가 상태로 표시합니다.

### P1 — 계정·권한

- 설치 시 관리자 bootstrap
- 가입 신청 및 관리자 승인·거절
- 로그인·로그아웃·토큰 갱신·비밀번호 변경
- 로그인 시도 제한과 세션 폐기
- 관리자 경로 LAN 차단 및 API role 검사
- 사용자 소유권 검사 공통 미들웨어/서비스 계층

완료 조건: pending 계정 로그인 차단, 타 사용자 자산 접근 차단, 외부 관리자 경로 차단, 관리자 최초 비밀번호 변경을 테스트로 증명합니다.

### P2 — 파일 업로드·다운로드

- 업로드 세션과 크기 예약
- 8MiB 청크 업로드 및 서버 오프셋
- 재개, 취소, 만료 세션 정리
- 최종 SHA-256 검증 및 원자적 파일 이동
- 사용자별 중복 검사와 별도 저장 선택
- 원본 다운로드 및 동영상 Range 지원

완료 조건: 네트워크를 중간에 끊고 앱을 재시작해도 업로드가 재개되며 최종 원본 SHA-256이 일치합니다. 타 사용자 자산 ID를 바꾸어 요청해도 접근할 수 없습니다.

### P3 — 미리보기·검색·앨범

- 이미지 미리보기 생성과 재시도
- EXIF 및 동영상 메타데이터 추출
- 날짜·파일명·카메라 정보·GPS 존재 여부 필터
- 앨범 생성·수정·항목 추가·제거
- 미리보기 API와 비공개 캐시 정책

완료 조건: 원본 바이트가 변하지 않고 메타데이터가 없어도 업로드가 성공하며 미리보기 생성 실패가 원본을 손상시키지 않습니다.

### P4 — 휴지통·용량·관리자 운영

- 30일 휴지통 및 복원
- 자동 영구 삭제 작업
- 사용자별 할당량·80% 경고
- 전역 디스크 임계값 및 업로드 차단
- 관리자 감사 로그·계정 관리·시스템 상태
- 매일 DB 백업 및 7일 보존
- 파일/DB 불일치 검사

완료 조건: 한도 초과 업로드를 서버가 거부하고 조회·다운로드는 유지합니다. 휴지통 복원 및 만료 삭제가 올바르게 작동합니다. DB 사본을 별도 복사본으로 복원할 수 있습니다.

### P5 — 모바일 및 관리자 UI

- Flutter 가입·로그인·라이브러리 UI
- 사진·동영상 선택과 업로드 대기열
- 중복 경고·오류 재시도·진행률
- 사진 탐색·검색·앨범
- 동영상 스트리밍·원본 다운로드
- 다중 선택 다운로드와 기본 갤러리 저장
- 관리자 React 페이지

완료 조건: 실제 Android 및 iOS 기기에서 파일 선택, 업로드, 스트리밍, 갤러리 저장을 각각 검증합니다.

### P6 — 인터넷 공개 및 안정화

- 도메인/DDNS와 Caddy HTTPS 구성
- 공유기 80/443 전달
- LAN 전용 관리자 경로
- 외부 모바일 네트워크 테스트
- SSD 미마운트·디스크 부족·재부팅 장애 테스트
- 접근 로그와 백업 복원 테스트

완료 조건: 외부에서 일반 앱을 사용하면서 관리자 페이지는 접근할 수 없어야 합니다. SSD가 없는 경우 저장소 변경 API는 실패하고 시스템 디스크에 사진 파일이 생성되지 않아야 합니다.

## 2. 필수 인수 테스트

| ID | 시나리오 | 예상 결과 |
|---|---|---|
| AT-01 | 가입 신청 직후 로그인 | 거부, 승인 대기 상태 반환 |
| AT-02 | 승인 후 로그인 | 성공 |
| AT-03 | 타 사용자 asset UUID로 조회/삭제 | 거부 또는 404 |
| AT-04 | 인터넷에서 관리자 URL/API 접근 | 프록시에서 차단 |
| AT-05 | 이미지/동영상 업로드 전후 SHA-256 비교 | 동일 |
| AT-06 | 업로드 청크 중 네트워크 단절 후 재시도 | 현재 오프셋에서 재개 |
| AT-07 | 해시가 동일한 파일 재업로드 | 중복 경고, 기본 건너뛰기 |
| AT-08 | 중복 파일 별도 저장 선택 | 새 자산 등록 및 용량 반영 |
| AT-09 | 사용자 사용량 80% 초과 | 관리자/사용자 경고 표시 |
| AT-10 | 사용자 할당량 초과 업로드 | 신규 업로드 거부 |
| AT-11 | 전역 디스크 임계값 도달 | 신규 업로드 거부, 경고 기록 |
| AT-12 | 서버 사진 삭제 후 복원 | 원본이 복원되고 휴대폰 원본은 영향 없음 |
| AT-13 | 휴지통 30일 만료 | 원본·미리보기·DB 관계 영구 정리 |
| AT-14 | SSD 미마운트 상태로 API 호출 | 파일 변경 실패, OS 루트 경로에 저장 없음 |
| AT-15 | DB 백업 복원 | 별도 복사본에서 DB 무결성 확인 |
| AT-16 | 사용자 A가 B의 해시와 중복 여부 질의 | B의 존재 여부가 노출되지 않음 |
| AT-17 | 앱에서 다중 다운로드 | 선택한 파일이 갤러리에 저장되고 실패 항목 표시 |
| AT-18 | 동영상 Range 요청 | 부분 응답 및 재생 탐색 지원 |
| AT-19 | 계정 보관 처리 | 로그인 차단, 사진 데이터 보존 |
| AT-20 | 비밀번호 및 토큰 로그 검사 | 원문 비밀정보 없음 |

## 3. 완료 정의

- 자동화된 단위 테스트와 API 통합 테스트 통과
- Android 및 iOS 실기기에서 주요 업로드·다운로드 흐름 검증
- 관리자 외부 접근 거부 테스트 통과
- 파일 무결성·용량 예약·휴지통 테스트 통과
- SSD 마운트 보호와 DB 복원 절차 검증
- 운영 배포에 필요한 환경 변수·서비스 설정·업데이트 문서 작성
